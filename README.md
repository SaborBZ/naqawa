## ✨ المميزات الرئيسية
- ⚡ **مزامنة فورية (Drift Guard):** تطابق تام بين حركة الشفاه والصوت حتى عند التقديم وتغيير السرعات.
- 🧠 **ذكاء اصطناعي فائق (Demucs v4):** عزل الآلات الموسيقية بدقة استوديو مع الحفاظ على الصوت البشري.
- ☁️ **دعم التشغيل السحابي:** عبر كروت شاشة Google Colab مجاناً (Tesla T4 GPU).
- 💻 **دعم التشغيل المحلي:** تشغيل مباشر على جهازك عبر المعالج (CPU) أو كرت الشاشة (CUDA GPU) لخصوصية 100%.

---

## 🚀 طريقة التثبيت في 3 خطوات (Chrome / Edge / Brave):

1. **حمّل الإضافة:** قم بتحميل ملف [`naqawa.zip`](https://github.com/saborbz/naqawa/raw/main/naqawa.zip) وفك الضغط عنه.
2. **افتح إدارة الإضافات:** في متصفحك، ادخل على الرابط `chrome://extensions` (أو `edge://extensions`).
3. **فعّل وضع المطور:** فعّل **Developer mode** من الزاوية العلوية، ثم اضغط على **Load unpacked** واختر مجلد الإضافة.
